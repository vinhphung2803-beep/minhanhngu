# Architecture (Chapter 1 + 2)

Plain HTML5 Canvas + vanilla JS, 320x180 logical resolution, fixed 60 Hz timestep. **Chapter 1's engine is reused, not duplicated**: `Player`, `Physics`, `Camera`, `Level`, `Renderer`, `Input` are the same classes everywhere (hub, social levels, Chapter 3).

| Module (file) | Role |
|---|---|
| `SaveSystem` (`js/save.js`) | one versioned save object, migrates the old Chapter 1 save |
| `Input` (`js/input.js`) | keyboard + **pointer** (mouse/touch) + on-screen buttons; `Input.key()` = real key presses |
| `CharacterAnimation` (= `Animator`, `js/anim.js`) | time-based clips, any sheet via `setSheet(key, set)`; physics hitbox is separate |
| `CharacterGrowth` (`js/growth.js`, `data/growth.js`) | stages (baby..young), `apply()` instant change, `evolve()` cutscene (pause, silhouette flicker, rays, flash, reveal, control returned) |
| `NPCSystem` (`js/npc.js`, `data/npc_data.js`) | NPC class: states, per-type conditions, commands, animation, draw |
| `UIManager` (`js/uimanager.js`) | buttons, icons, stars, bars, badge pop-ups on top of `UI.panel` / `Text` |
| `MinigameBase` / `MinigameManager` (`js/minigame.js`) | lifecycle, level select, result screen, records progress |
| `PaintingMinigame` (`js/paint.js`) | tools, regions, evaluation |
| `LanguageMinigame` (`js/language.js`) | match / sort+sentence / detective |
| `SocialMinigame` (`js/social.js`) | walkable social room, menu, plates + gates |
| `DiscoverMinigame` (`js/discover.js`) | sequences the three engines with checkpoints |
| `ProgressionManager` (`js/progression.js`) | scores, stars, stats, unlocks, rewards, growth milestones |
| `AchievementManager` (`js/achievements.js`) | badge rules from `data/progression_data.js` |
| `ChapterWorld` (`js/world.js`) | walkable chapter map with stations (Chapter 2 hub, Chapter 3 placeholder) |
| `Game` (`js/main.js`) | state machine: title, select, howto, card, dialogue, play, hub, minigame, evolve, complete, ending |

## Data files (edit without touching code)
`text_ch2.js` (all words) · `text_ch3.js` · `vocab.js` · `paintings.js` (generated by `tools/make_ch2_assets.py`) · `social_levels.js` (generated by `tools/make_social_levels.py`, plain text) · `levels_ch2.js` (hub + Chapter 3 map) · `npc_data.js` · `growth.js` · `progression_data.js` · `minigame_data.js` · `chapters.js`.

## Adding a mini-game (e.g. for Chapter 3)
```js
class MyGame extends MinigameBase {
  update(dt) { super.update(dt); /* ... */ this.finish({ score: 500, stars: 2, stats: { creativity: 12 } }); }
  render(ctx) { /* draw */ }
}
MinigameManager.register('mine', MyGame);          // + add 'mine' to PROGRESSION.levelsPerGame
```
Add a station letter in `data/levels_ch2.js` (see `Level` constructor for `A L F D`) or call `Game.openMinigame('mine')` from any `ChapterWorld`. Progress, stars, stats, badges and saving are automatic.

## Adding a chapter
1. Level rows in `data/` (hub-style with stations, or platformer).  2. Add an entry in `data/chapters.js` (`kind: 'world'` + `world: {id, rows, startStage, text, exitTo}`).
3. For a new growth form add a row in `data/growth.js` + a sheet from `tools/make_characters.py`; call `CharacterGrowth.evolve(Game, 'stage', cb)`.
